# Cage front-layer asset prompts

These four square cage overlays were generated with the built-in ImageGen tool from the existing cage sprites as edit/style references. Each prompt preserved the cage design while requesting only the fully opaque front bars, door, lock, base rail, and front-facing ornaments, with transparent openings and no rear cage geometry. Runtime copies are resized and alpha-cleaned for layering over each animal sprite.

- Golden Heart: `cage-golden-heart-front-v2-master.png`
- Storybook Wood: `cage-storybook-wood-front-v2-master.png`
- Moon Silver: `cage-moon-silver-front-v2-master.png`
- Garden Vine: `cage-garden-vine-front-v2-master.png`

The common output intent was a centered 1:1 cute chunky anime fantasy JRPG game sprite, matching the original cage's material, lighting, palette, camera, scale, and placement, with no animal, text, watermark, external shadow, or redesign.
