# Feedback on v0223

1. Good implementation of the volume sliders - though the default should definitely be lower music volume and higher SFX volume - setting music volume to around 10% and leaving SFX at 100% sounded about right on my phone and desktop which is a weird ratio to have to set it to, let's make that the default and then scale / normalize / adjust that so they show as 75% for both in the UI so you can still adjust from there but the default balance is about right. 
2. Possible slight regression in mobile phone layout where the directional pad is now covering more of the UI and you can't see the minimap at the same time as the directional pad. But we need to overhaul and align the mobile UI layout to desktop and iPad anyway since mobile layout is just pretty busted still since v0220
3. Not specific to v0223 - but campaign maze named: Springstep Sky Hollow feels inverted and it's actually pretty disorienting. Basically whether intentionally or not we have basically set a precedent or expectation through repetition that the floor texture should be lighter than the wall textures, buy in sky hollow the walls are light and look like floors and the floor is dark and looks like floor. I think we should keep this consistent so it's always clear what is floor and wall. This might be redundant once we've overhauled tbe lighting and the wall 3D effect to make the walls look more 3D and give the game more of a sense of depth. This will make it obvious what is wall what is floor.
4. It's a bit weird for me to have movement speed in the settings sub menu - I feel like it should be an icon on the right hand UI ideally with three different icons one for slow, walk, and zip so you can see at a glance which one is active and can easily change it. 
5. Also that menu with graphics and music options feels weird to use the sound icon for that I feel like we need an icon sprite that shows the sound icon and a cog together so it's clear that menu option is for the sound and settings menu. We can have movement speed in there too but should also be in the main UI since its important and people will want to change it. Slow movement does feel more smooth by the way. But I still like zip sometimes. Default should be the middle option. 
6. I didn't look for anything else in particular when testing v0223 - I will go through the specific items you want me to playtest when I get time.
